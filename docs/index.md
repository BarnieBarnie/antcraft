# AntCraft

A Fabric mod for Minecraft that adds bots you program. Each bot runs a script written in a small subset of Python: it walks where the script sends it, mines, places, crafts, smelts and fills chests, and the script decides what comes next. A bot with nothing to run walks home, through a nether portal if its home is in another dimension, and waits there. [Colonies](features/colonies.md) split work between bots with a library of default scripts (see the [roadmap](design/index.md#roadmap)).

The bots are in-game entities and are not linked to real accounts. This is a hobby project, made for fun in your own worlds.
